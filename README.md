# *SMART BCN - CLEAN & SAFE BCN*
### This project has been done focused on the application of cps (cyber-physical systems). 
### Our main idea was to increase security in the city of Barcelona and its cleanliness using robots and communications between them.  
### In the *PROJECTE_ ESTUDI DE CONTEXT* file, it can be seen the most theoretical part of the project, where it shows how it would be designed and developed and who would the stakeholders be.  
### In the *PROJECTE_ ESPECIFICACIÓ DE REQUISITS* file, it can be seen the most technical part of the project, where, through UML class diagrams and use case diagrams, it  shows which functionalities it would have and how would they be developed.
